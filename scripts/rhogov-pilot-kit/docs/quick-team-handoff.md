# Quick team handoff

## Two-minute demonstration

1. Open the **DEMO · SYNTHETIC** workspace. State up front that every participant and result is fictional.
2. Show the primary cohort: 6/10 qualifying first attempts; three distinct participants hit the same faucet step; a later retry by P07 does not replace the first attempt. A review note is recorded against that evidence checkpoint.
3. Open the experiment card. Show that the pilot clock starts only after the group approves V1, and that changes append a linked amendment.
4. Start a blank workspace to show where the team would record its real action, network, electorate, data audience, consent plan and evidence rule.
5. Export the report. It separates supported observations, self-reports, unknowns, missing participants and retries. No live result or network action is claimed.
